# V7.2 - Hướng dẫn nhanh

Chạy từ thư mục gốc `node server/server.js` với `CHEMMAP_DEMO=1` (chỉ dùng thử) hoặc dùng `START_CHEM_MAP_WINDOWS.bat`. Mở http://127.0.0.1:8080/ để vào cổng quản trị / học sinh, http://127.0.0.1:8080/live để vào kho tự luyện theo chương, bài.

Yêu cầu Node.js 22.13+, không cần API key. Tác giả Lê Bá Nhẫn – Trường THPT Hòn Đất.

Tài khoản demo chỉ xuất hiện lần đầu khi khởi tạo DB, mật khẩu được sinh ngẫu nhiên và hiển thị trong cửa sổ lệnh. Dừng server và sao lưu thư mục `server/data/` để lưu dữ liệu. Đọc README.md ở thư mục gốc trước khi triển khai thử nghiệm.
